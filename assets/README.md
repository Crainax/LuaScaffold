# 最小地图来源

`map/` 的六个文件由本机 InnerJAPI 1.49-9 包的示例测试地图提取，作为构建最小地图的地形和元数据载体：war3map.doo、war3map.shd、war3map.w3e、war3map.w3i、war3map.wpm、war3map.wts。

不包含原示例地图的 war3map.j、单位预放置或业务脚本。构建工具更新 W3I 的标题/作者/描述/玩家数文本，重新生成 main/config、六个静态玩家槽及固定引导 JASS。模板内的字体与 core 贴图直接取自有哈希记录的 vendor。

这是用于验证和开始开发的最小地图，不是完整地图编辑管线。实际项目可以替换地形和对象数据；更换后应重新验证脚本生成、资源打包和玩家初始化。
