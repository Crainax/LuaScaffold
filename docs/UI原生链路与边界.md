# UI 原生链路与边界

业务可使用 Lua 官方风格控件，不需要再在 JASS 业务层写 DzFrame。它仍通过本地原生接口调用游戏 frame 系统，Lua 不是独立的软件绘图引擎。视口裁剪有官方接口；连续滚动无需整格翻页。字体的实测结果则不支持“任意字号都能生效”的结论。

## 证据分层

| 层次 | 本次确认 | 不能据此推断 |
| --- | --- | --- |
| Lua 源码 | panel/text/model 等对象调用 jass.japi；set_scroll_y 接受数值偏移并刷新子控件坐标 | 原生实际像素、显卡路径、所有控件都没有缺陷 |
| 官方文档 | FrameSetViewPort 开启后，子控件超出父面板的部分不渲染 | 原生命中测试必然同样裁剪，所有模型类型与嵌套都无例外 |
| 二进制 | 固定载体嵌入 x86 PE，注册 frame 接口并调用游戏函数；viewport wrapper 写标志位 | 仅凭名字断言它使用 D3D scissor、另一个 UI 引擎或特定渲染后端 |
| 原生测试 | 小数滚动坐标、祖先命中裁剪、嵌套对象/模型生命周期、文字读回与字号尺寸采样 | 人眼看到的裁剪边缘、模型越界像素、实际鼠标/输入法及多分辨率外观 |

官方描述见 [设置控件视口](https://japi.war3rpg.top/1.44/设置控件视口.html)。本次没有用桌面截图或系统输入，视觉和真实交互的未覆盖项保留在文末人工检查步骤中。

## 固定 DLL 的静态路径

`wenhao_plugin.tga` 实际是 PE 载体。外层导出 call/get，通过资源承载嵌入镜像；文件偏移 `0x60ae0` 处的引擎 PE 长 7,499,264 字节，SHA256 为 `5c44196eb2b82a11ccf8754a259193db86dc4c823140887b0442741d48132a8c`，ImageBase 为 `0x10000000`。另一个 PE 在 `0x78d360`，本次没有据此展开无关功能。

可复现工具：在忽略的 `build/analysis-deps` 安装 pefile/capstone 后运行 `python tools/engine_trace.py`、`python tools/inspect_engine.py --image build/engine-pe/pe-60ae0.dll --output inner-engine-static.json`。工具只解析文件，不 LoadLibrary，不给游戏注入新的分析 DLL，不修改原始载体。

`FrameSetViewPort` 注册回调为 VA `0x1024bdd0`、签名 `(IB)V`。函数判断 frame 非零，再置位/清除 `frame+0xC` 的 bit 0。它本身没有直接执行绘图。检索到的若干同偏移 test 指令只是候选，其中有栈变量与其他类型，不能当作已追通的渲染调用链。因此已确定的是 Lua→JAPI 注册→frame 标志，最终绘制消费者尚未可靠定位。

`FrameSetTextFont` 注册回调 VA `0x1024adf0`、签名 `(ISR)V`。wrapper 通过 `ChannelPanel` 字符串定位游戏字体函数并传入字体与 real 尺寸，wrapper 本身没有直接的字号 clamp。继续对磁盘 Game.dll 静态追踪，得到以下路径：

```text
InnerJAPI 0x1024adf0
  → ChannelPanel 游戏字符串 0x6f97f0ac / 引用操作数 0x6f2b8034
  → 0x6f09ce60 → 0x6f099ac0 → 0x6f17f870
  → 0x6f0cebd0 → 0x6f0da530
```

这份 Game.dll SHA256 为 `e04d1716603c075eb0c8e1e21cf1093a664adc5249efab396bfa08d7b09d0c3a`、ImageBase 为 `0x6f000000`。`0x6f17f870` 路径先经除以约 0.6 的换算，并对该层浮点值限制到 1.0；下层 `0x6f0da530` 调用 `0x6f0d0310` 进行尺度转换，随后 `cvttss2si` 转整数，在 `0x6f0da5ad` 比较 `0x20`，超过时于 `0x6f0da5b2` 置为 `0x20`，最终写入对象 `+0xa4`。因此确实存在**转换后整数尺寸的 32 上限**，不是仅靠字体测量猜测。

尺度转换依赖全局量和调用参数；本次没有读取运行中该函数的寄存器与全局值，也没有证明磁盘代码未被加载器 hook。不能把上述常量直接换算成所有分辨率、字体下的 Lua `font_size` 上限，更不能说 Lua 最大字号就是 32。静态限制与本次实测平台期相互支持，但每一步实际参数值仍未动态追踪。可复现记录为 `research/evidence/game-font-trace.json` 和 `tools/trace_game_font.py`。没有为绕开限制 patch Game.dll。

还有一个应保留的静态差异：plugin wrapper 压入两个栈参数并清零 edx，而上述磁盘定位函数读取第三个栈参数并以 `ret 0xc` 返回。进程模块枚举在本机权限下失败，因此本次没有确认实际加载镜像和 hook 后调用约定。不能仅凭磁盘反汇编把它判为已发生的栈错误，也不能忽略该差异并宣称已动态追通字体路径。当前原生实测未出现该接口崩溃；这一点仍应随引擎升级重新检查。

`DestroyFrame` 注册回调在 `0x102491a0`：先调用两个以 frame 为键的表处理函数，再以参数 1 调用对象虚表 `+0xd8`。`RegisterFrameEvent` 在 `0x1024e4e0` 操作的表根是 `0x106e6150`，它也出现在前述第一个清理函数中。这证明 Lua destroy 有实际原生处理链，不能把它说成“只删 Lua 表”。本次未动态枚举原生 frame、字体或事件注册的全部存量，因此也不能仅凭该路径宣称 native 零泄漏；长测的进程资源趋势另列。

## 连续滚动及输入修订

构建 `panel {is_scroll=true}` 自动启用原生 viewport；普通嵌套面板可用 `clip_children=true`。`panel:set_scroll_y(17.25)` 允许小数滚动，范围限制为内容溢出的高度，不需要把整行隐藏/显示来模拟分页。滚动条比例使用父面板可用行程，并处理空内容、零行程。

原包曾把部分负 X 位置的控件直接隐藏，现只在完全离开屏幕时隐藏。命中测试计算自身矩形与所有开启裁剪的祖先矩形交集。按下、点击、悬停、滚轮和常规快捷键使用可见区域规则；显式 hide_has_event 仍是开发者要求的隐藏快捷键例外。

滚轮在命中且可见的面板中优先选最深层，平级按 level 与本地创建序号选择一个，避免嵌套内外一起滚动。该排序是本模板的输入策略，不是声称复刻引擎所有遮挡关系；复杂重叠 UI 应显式组织层级和交互区域。

FDF 临时文件原来共用 ui/Load.fdf；多开客户端可能互相覆盖。现在按项目 ID/玩家槽隔离为 `<id>-ui/Pn-*`。这只是本地资源文件身份，不能用于分配同步实体 ID。构造失败也会清理已创建的 frame/背景控件。

可复用示例：`examples/scroll_view.lua`，包括持续 0.5 单位偏移、长列表、嵌套裁剪和 Footman 模型。通过开发 view loader 加载，停止/替换时统一销毁。

## 字号实验

`research-ui-02` 对同一个 text 逐次设置 8、16、16.5、32、64、128、256，并等待布局刷新后读取 native text metrics。高度从约 14.4966 增至 23.1946，之后保持不变；“应扩大两倍”的探索断言失败。即时同回调读取还曾返回完全相同的旧尺寸，故不能把 setter 后立刻读到的结果当成最终布局。

`research-ui-03` 改用每个字号单独创建 FDF 模板，也测到同样的高度平台期。这里覆盖的是固定字体、当前游戏与这些采样点；不能宣称精确 clamp 常量是 16，也不能说所有字体/分辨率一定相同。小数参数能传入不等于像素能连续变化。

修正模板名整数截断冲突及 font_path 缓存比较后，构造字号以 0.01 为模板缓存精度。项目应使用有限字体样式，避免每帧制造新 FDF 字号模板。超大标题可另评估图像字、模型字或经验证的整体缩放方案；本次没有承诺这些替代方案已完成。

上述小数字号适配与采样针对 `text`。`edit` 仍使用原包的整数字号 FDF 模板，业务应传正整数，不能把 text 的小数参数支持套到输入框。未覆盖的控件方法应先查实现和对应测试，不能从“官方 UI 已接入”推导所有方法都有相同的输入范围。

## 人工视觉验收步骤

使用“Lua: 启动开发地图（保留游戏）”，将 scroll_view.lua 复制到游戏目录 `<id>-dev/view.lua`。观察长列表是否在父面板边缘逐像素被裁掉；拖动/滚轮滚到半行，再点击可见与被裁掉部分；嵌套区内滚动应只滚内层。检查模型是否越界显示、隐藏面板是否仍抢输入，随后改变分辨率并比较中文字形和字号。

这些步骤需要用户操作原生游戏界面，自动测试没有执行。模板当前的支持结论以日志中的 API/生命周期/同步断言为界。
